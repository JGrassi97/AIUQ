How to use the AIUQ dashboard

Two apps

Monitor
Read-only. Follow every Autosubmit experiment: what runs now, how the run went, and the forecasts it wrote.
Launcher
Create a new experiment, launch, resume or stop its run, delete it. Every action asks for confirmation and is logged.

The experiments panel

Experiments are grouped by state: running, not finished, completed. The ring shows how many jobs are done. Type in the filter to search by id, model, initial conditions, start date or description. Moving the pointer over a row loads it in advance, so opening it is immediate.

An experiment

Live
Running and queued jobs, the progress grid (one square per job), initial conditions, GPUs, problems.
Run review
Setup, timeline, how long jobs take and how much is left, HPC performance.
Data
Maps and time series of the outputs, spread growth, Hovmöller, comparison across start dates.
Job details
Click a square, a timeline bar or a job name: its attempts and logs open in a panel on the right, without leaving the page.
